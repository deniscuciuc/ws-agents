# Workflow: Open-Source Modernization

## Trigger
When assessing or improving an open-source project's health and contributor experience.

## Steps
1. Audit current state against opensource-maintainer checklist
2. Fix documentation gaps (README, CONTRIBUTING, LICENSE)
3. Add templates (.github/ISSUE_TEMPLATE, .github/PULL_REQUEST_TEMPLATE)
4. Set up CI/CD
5. Configure dependency management (Dependabot/Renovate)
6. Set up release automation
7. Add code of conduct

## Checklist
See `opensource-maintainer` persona for the full audit checklist.

## Priority Order
1. LICENSE and README (legal + discoverability)
2. CI/CD and tests (quality signal)
3. Templates and CONTRIBUTING (contributor friction)
4. Release automation (maintainer burnout)
5. Dependency management (security)
